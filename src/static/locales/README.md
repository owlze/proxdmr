# Локализация ProxDMR (i18n)

В этой папке хранятся словари переводов интерфейса ProxDMR в формате JSON.

## Как добавить новый язык (например, Немецкий - Deutsch):

1. Скопируйте файл `en.json` и назовите его по коду языка, например `de.json`.
2. Откройте `de.json` и переведите значения справа от двоеточия (ключи слева не изменяйте!).
3. Откройте файл `src/static/js/i18n.js` и добавьте ваш язык в массив `SUPPORTED_LANGUAGES`:
   ```javascript
   { code: "de", name: "Deutsch", flag: "🇩🇪" }
   ```
4. Готово! Новый язык автоматически появится в выпадающем списке в настройках станции (раздел «Общие»).
