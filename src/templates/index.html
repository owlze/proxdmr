🔑 Как получить API v2 Key в BM:
  1. Откройте brandmeister.network ↗ и авторизуйтесь.
  2. Нажмите на свой позывной / круглую аватарку в правом верхнем углу сайта (выпадающее меню профиля пользователя).
  3. В выпадающем меню выберите «Profile Settings» (Настройки профиля).
  4. На открывшейся странице перейдите в блок / вкладку «Security Settings» (Настройки безопасности).
  5. Нажмите кнопку «API Keys».
  6. В появившемся окне нажмите кнопку «+ Add» (или «Add Key») для генерации нового ключа.
  7. Скопируйте полученный API v2 Key (длинная строка JWT-токена), вставьте его в это поле и сохраните хотспот.
⚠️ Важный нюанс BM: полный текст сгенерированного API-ключа (длинный JWT-токен) показывается во всплывающем окне только один раз в момент создания. После закрытия окна просмотреть его повторно невозможно (в целях безопасности) — можно только сгенерировать новый ключ.
💡 Зачем это нужно: Позволит веб-трансиверу ProxDMR привязывать/отвязывать статические TalkGroups (TG) и мгновенно сбрасывать зависшие динамические группы (TG 4000) прямо из интерфейса.
  1. Откройте вкладку токенов в личном кабинете TGIF: tgif.network/profile.php?tab=StaticTokens ↗ и авторизуйтесь.
  2. Убедитесь, что для вашего хотспота настроен персональный Hotspot Security Key (API статических групп требует защищённого подключения и не работает со стандартным паролем passw0rd).
  3. На вкладке «Static Tokens» выберите или укажите ваш хотспот (полный ID с учётом SSID, например 250xxxx01).
  4. Сгенерируйте Static TG API Token для этого устройства.
  5. Скопируйте полученный токен, вставьте его в поле выше и сохраните настройки хотспота.
⚠️ Важный нюанс TGIF: каждый API-токен привязывается к конкретному ID хотспота (DMR ID + SSID). Сервер TGIF позволяет назначить до 5 статических групп на устройство, а служебные группы (9, 777, 4000, 9990, 31000) вызываются только динамически через PTT.
💡 Зачем это нужно: Позволит ProxDMR управлять статическими TalkGroups (TS1 / TS2) на стороне TGIF Network через Менеджер TG и автоматически настраивать группу при быстром вызове.
Передаётся в пакете RPTO сразу после подключения (например FreeDMR: TS1=2501;TS2=250;DIAL=0; или DMR+: StartRef=4370;RelinkTime=60;)
Настройка хотспота в сети FreeDMR:
  • Пароль хотспота: по умолчанию большинство серверов используют passw0rd, либо ваш персональный пароль из портала FreeDMR Portal.
  • Статические группы (TS1 / TS2): можно редактировать вручную в строке выше ИЛИ через визуальный менеджер по кнопке «⚡ Управление TG» на карточке хотспота.
  • Дополнительные параметры RPTO: TIMER=10 (таймаут динамических TG в мин.), SINGLE=1 (режим одной активной TG), VOICE=0/1 (голосовые подсказки), DIAL=0 (TG по умолчанию).
  • Сброс динамических TG: отправка вызова на TG 4000 или кнопка сброса в менеджере TG.
  • Голосовой маяк: VOICE=0 отключает 15-минутную голосовую идентификацию сервера и озвучку переключений (рекомендуется для ProxDMR, чтобы не засорять запись и транскрипцию). Для тональной отбивки без голоса можно указать LANG=CW.
На рефлекторах XLX голосовая работа ведётся в TS2: выбранный модуль A–Z автоматически привязывается к TG 4001–4026 (пароль стандартный: passw0rd)
Как работает связь с рефлектором XLX:
  • Порт и пароль: стандартный порт MMDVM для XLX — 62030, пароль — passw0rd.
  • Таймслот 2 (TS2): протокол XLX MMDVM работает только на TS2. ProxDMR автоматически направляет команды и голос в TS2.
  • Модули A–Z (TG 4001–4026): модуль A = TG 4001, B = TG 4002, ..., Z = TG 4026. Отключение от модуля — TG 4000.
  • Голосовой вызов (TG 9): после привязки к модулю весь голосовой обмен в рефлекторе идёт в группе TG 9 на TS2. Переключать модули на лету можно через кнопку «⚡ Управление модулями XLX» на карточке хотспота.
